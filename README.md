# 数学関数学習アプリ開発（デジタルハリウッド大学 2019年 2Q）

## 概要
デジタルハリウッド大学 2019年度 2Qで、先生から数学関数を学習するアプリ作成を依頼されました

周期関数・偶関数／奇関数・三角関数の直交性・フーリエ級数展開・フーリエ変換など、数学関数の定義や性質を1行ずつ順番に表示しながら学習できる Android 向けアプリです。

## 使用技術
| 分類 | 技術 |
| --- | --- |
| フレームワーク | Apache Cordova（cordova-android 8 / cordova-ios 5） |
| 言語 | HTML / CSS / JavaScript |
| UI | Bootstrap 4.3.1、jQuery 3.4.1 |
| 数式表示 | MathJax 2.7.9（`TeX-AMS-MML_HTMLorMML` 設定で LaTeX を描画） |
| Cordova プラグイン | cordova-plugin-file、cordova-plugin-dialogs、cordova-plugin-device、cordova-plugin-whitelist、ファイル選択系プラグイン（cordova-plugin-chooser など） |
| 対象プラットフォーム | Android（iOS プラットフォームも追加済みですが、アプリ本体は Android 側のみ実装） |

## 工夫した点
- 関数の表示はカスタムテキストにLaTexフォントで表示します
  - 当初は ASCIIMath 形式で記述していましたが、表現力を上げるため LaTeX 形式に変更しました
  - MathJax は `delayStartupUntil=configured` で読み込み、テキストファイルの内容を DOM に展開してから `MathJax.Hub.Configured()` で描画を開始することで、動的に追加した数式も正しく表示されるようにしています
- 学習内容をアプリに埋め込まず、外部のテキストファイル（`.txt`）から読み込む方式にしました
  - 「ファイル選択」ボタンで端末内の任意のテキストファイルを読み込めるため、先生や学習者が自由に学習内容を差し替えられます
  - 最後に読み込んだファイルはアプリのデータ領域に `last_read_file.txt` として保存され、次回起動時に自動で読み込まれます
- 内容を一度に全部表示するのではなく、「続く」ボタンで1行ずつフェードイン表示し、板書のように順を追って理解できるようにしました
- 「やり直す」ボタンで表示中の項目を最初から見直せるようにしました

## 設計
### 処理の流れ
1. アプリ起動時、`deviceready` イベントで `app.readDataFile()` を実行
2. アプリのデータ領域にある `last_read_file.txt` を読み込む
   - 存在しない場合は同梱のデフォルトファイル `www/resource/math_function.txt` を読み込む
3. テキストを1行ずつ解析し、DOM に非表示の要素として展開
   - 行頭が全角の `＃` の行 → 項目のタイトル（`#title{n}`）
   - 空行以外のそれ以外の行 → 項目の内容（`#content{n}`）
   - 項目ごとの区切り位置（タイトル番号, 最後の内容番号）を hidden input に保持
4. MathJax で LaTeX の数式を描画し、1つ目の項目のタイトルを表示
5. ボタン操作
   - 「続く」：現在の項目の内容を1行ずつフェードイン表示
   - 「前へ」「次へ」：前後の項目に切り替え
   - 「やり直す」：現在の項目の内容を非表示に戻す
   - 「ファイル選択」：選択したテキストファイルを `last_read_file.txt` に書き込み、画面を再読み込み
   - 「終了」：アプリを終了

            ├── css/
            │   ├── index.css
            │   └── bootstrap.min.css
            ├── js/

> `js/MathJax` には MathJax 2.7.9 のうち、`TeX-AMS-MML_HTMLorMML` 設定・拡張機能・TeX Web フォント（woff）・英語／日本語ロケールのみを同梱しています（約7MB）。他の設定やフォントが必要な場合は `npm pack mathjax@2.7.9` で取得して追加してください。

### 開発時のルール
- アプリ本体のソースは `platforms/android/app/src/main/assets/www/` を直接編集しています（ルートの `www/` は Cordova テンプレートのままです）
- 学習内容はソースに埋め込まず、テキストファイルで管理します
- 学習内容テキストの書き方
  - 文字コードは UTF-8
  - 項目のタイトルは行頭に全角の `＃` を付ける
  - 数式は LaTeX で記述し、`$...$` または `\(...\)` で囲む
  - 1行が「続く」ボタン1回分の表示単位になる（空行は無視される）

  ```
  ＃周期関数の定義

  $f\left(x\right)$が周期関数である

  $f\left(x+nL\right)=f\left(x\right)\ \ \ n\in \mathbb{Z}$（$n$は整数）
  ```

## 主な仕様
- 学習内容（タイトル・数式を含む本文）をテキストファイルから読み込んで表示
- デフォルトの学習内容は以下の23項目
  - 周期関数の定義、周期関数の積分に関する性質
  - 偶関数・奇関数の定義、積、積分に関する性質、任意の関数の偶関数部分と奇関数部分
  - クロネッカーのデルタ、三角関数の直交性
  - 実フーリエ級数展開・複素フーリエ級数展開（基本周期 $2\pi$ ／一般周期）
  - オイラーの関係式、三角関数とオイラーの関係式、関数 $e^{inx}$ の直交性
  - フーリエ変換とフーリエ逆変換
- ボタン一覧

  | ボタン | 動作 |
  | --- | --- |
  | 前へ | 前の項目へ移動（最初の項目では非表示） |
  | 続く | 現在の項目の内容を1行ずつ表示（すべて表示すると非表示） |
  | 次へ | 次の項目へ移動（最後の項目では非表示） |
  | やり直す | 現在の項目の表示を最初からやり直す |
  | ファイル選択 | 端末内のテキストファイルを選択して学習内容を差し替える |
  | 終了 | アプリを終了する |
- 読み込んだファイルは保存され、次回起動時も同じ内容で学習を再開できる
